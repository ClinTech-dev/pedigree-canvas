## Bennett/NSGC issues seen
- Sex assigned at birth renders as **"AFAB"** without the parentheses the standard (and `bennett-pedigree-standards.md` §2) gives as "(AFAB)".
- On canvas, **NB and unknown sex look identical** (plain diamond). The panel's "?" diamond icon suggests the canvas would differ. The standards doc allows a diamond for both, but Margaret teaches the distinction, and the mismatch between icon and output will confuse students.
- The unknown-zygosity "?" sits **above** the twin apex on the descent line, not between the twin lines.
- **No carrier notation**. The pattern options (diagonal, dots, crosshatch, stripes) are not the Bennett centre-dot carrier symbol. Margaret would teach carriers and notice this.
- The Key lists only conditions. Symbols (deceased, SB, SAB, adoption, twins) are not keyed, which is acceptable under Bennett because they are standard.
- **Correct** in the symbol tour (P4-8): SB (sex symbol + slash + "SB"), SAB (open triangle + "SAB"), adopted-in (brackets + dashed line), consultand (arrow with no P), infertility (double bar), MZ (bar between the twin lines).
- Layout rule "lines do not cross": line-line crossings are avoided, but lines run through text labels.

## Deviations (Playwright-driving issues, not app problems)
- On the first **New**, Playwright auto-dismissed the native `confirm()`, so nothing happened. A dialog handler accepted it on the second try. A human would simply have seen the dialog.
- DZ button tooltip: headless screenshots do not show native `title` tooltips, so the "Dizygotic twin" text was read from the element's title attribute. A human would see it by hovering.
- Some clicks on "empty canvas" to deselect landed on or kept a person selected. Escape did not deselect. This affected panel state between steps, not the outcome.
- Taking a screenshot of the exported SVG opened directly as a file timed out, so it was rendered via an `<img>` wrapper page. The PDF was rasterised with `pdftoppm`.
- Panel fields were sometimes reached by placeholder text or scrolled into view programmatically, where a human would scroll the panel by eye. The KLM counts these as one point + click each.
- `bennett-pedigree-standards.md` was read only after drawing and exporting, for scoring. It mentions a "Mark selected as twins" command, which Margaret never found in the UI (⌘K "twin" with nothing selected shows no match). That command may need a multi-selection first.
