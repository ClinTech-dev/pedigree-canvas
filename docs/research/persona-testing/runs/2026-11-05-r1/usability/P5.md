## Bennett/NSGC issues seen
- **Multiple conditions are not distinguished by default.** Bennett uses a different quadrant or pattern for each condition. The app offers quadrant, colour and pattern pickers, but defaults the second condition to the same quadrant and fill as the first. A low-literacy user accepts the defaults and gets an ambiguous pedigree and Key.
- **Age at death / onset:** "d. 60" for "60s" is falsely precise. There is no visible way to say "approximately". The cause of death ("?stomach trouble") is not drawn, although the standards expect uncertain causes to be noted with "?" or a note.
- **Test result:** "BRCA2" on the symbol without "VUS" can be misread as a pathogenic variant. The result belongs on the symbol, not only in the Key.
- **Sibship order:** the older brother is placed to the right of the proband.
- Correct: deceased slash, proband arrow + P, the twin single apex with "?" for unknown zygosity, generation numerals on the canvas.

## Deviations (Playwright driving, not app problems)
- The repo's local `playwright` package wanted a browser build that isn't installed, so I used the machine's global Playwright instead. The first driver run crashed before any interaction.
- My first step file was read half-written by the watcher ("fn is not a function"). Fixed with an atomic rename, and no app action was lost.
- I set the twin-zygosity dropdown with a role locator (`select` → "Unknown zygosity"), not a pixel click. This is equivalent to choosing from the visible dropdown.
- Text was entered with `keyboard.type` after clicking each field. This is ordinary typing, not a shortcut. Jess used no keyboard shortcuts.
- Screenshots were reviewed after each step, so the persona never had to "search" for controls by trial. The KLM estimate assumes first-time discovery in the same place, which may flatter real first use.
